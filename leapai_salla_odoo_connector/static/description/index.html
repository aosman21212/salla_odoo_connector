Quick Setup Guide
Get connected in under 5 minutes
1

Install the module

Go to Apps → Search "Salla Odoo Connector" → Install. Dependencies (Sale, Stock, Contacts, Accounting) are installed automatically.

2

Create a Salla App

Log in to salla.dev, create a new app, and copy the Client ID and Client Secret. Set the redirect URI to https://your-odoo.com/salla/callback.

3

Create a Salla Instance in Odoo

Navigate to Salla Connector → Instances → New. Enter the Client ID & Client Secret, then click 🔑 Get Token to authorise via OAuth 2.0.

4

Test the connection

Click ✅ Test Connection. If successful, the store name, email and domain are populated automatically.

5

Run the Import Wizard

Click 📥 Open Import Wizard on the Import tab. Select the data types to import and click Start Import.

6

(Optional) Enable Auto-Sync

Click ⚙ Configure Scheduler, toggle Enable Scheduled Sync, choose your interval, and save. A background cron job will keep everything in sync.
